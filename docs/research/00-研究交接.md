# EasySteer × ReBalance 研究交接

更新日期：2026-09-07

## 当前结论

EasySteer 的目标子集、SEAL 示例、ReBalance 静态版和作者代码逻辑的动态版，均已在单张 RTX 4090 D 上运行。当前最重要的两条 ReBalance 结果是：

- 静态编译版：token 减少 32.7%，准确率下降 3.0 个百分点，时间 28.9→27.3 秒；
- 动态编译版：token 减少 16.0%，准确率不变，时间 28.9→45.0 秒。

这说明方法复现与框架适配已经成立。动态版目前用更多 token 换回准确率，但每步置信度计算造成明显开销；下一阶段应先优化速度，再拟合新控制函数。

## 版本含义

| 名称 | 实际内容 | 状态 |
| --- | --- | --- |
| EasySteer 基础链路 | vLLM 加载、生成、 `SteeringSpec` 干预 | 已完成 |
| SEAL-EasySteer | 仓库示例向量和固定系数 | 机制复现，不是论文完整复现 |
| ReBalance static | 作者公开向量、层18、换段边界、固定系数 -1 | 已完成 |
| ReBalance official-code dynamic | 逐请求置信度、相邻步骤方差、作者动态函数 | 已完成，性能待优化 |
| ReBalance paper-faithful dynamic | 论文几何平均置信度及重新校准函数 | 未实现 |

论文的步骤置信度是最大 token 概率的几何平均；作者公开 Qwen2 代码使用算术平均。当前动态版有意对齐公开代码，不能标成论文公式版。

## 主实验结果

每一行都使用该次运行自己的配对 baseline，不应跨行比较 baseline。

| 实验 | 数据 | Baseline | 方法 | Token变化 | 准确率变化 | 时间 |
| --- | --- | --- | --- | ---: | ---: | ---: |
| SEAL | MATH-500，100题 | 72.0%，4125.3 | 75.0%，3248.4 | -21.3% | +3.0 pp | 102.5→106.2秒 |
| ReBalance 静态编译版 | GSM8K，200题 | 85.5%，1010.5 | 82.5%，679.6 | -32.7% | -3.0 pp | 28.9→27.3秒 |
| ReBalance 动态编译版 | GSM8K，200题 | 85.5%，1010.5 | 85.5%，848.6 | -16.0% | 0.0 pp | 28.9→45.0秒 |

逐题变化分别为：SEAL 改善/退化 12/9，静态 ReBalance 7/13，动态 ReBalance 6/6。小样本冒烟结果仅用于排错：SEAL 20题 token -17.6%；静态20题 token -27.2%；动态20题 token -29.0%。

## 已完成与待办

已完成：环境、基础生成、SEAL 20/100题、ReBalance 静态与动态20/200题、逐请求状态隔离、作者函数和编译路径。

优先待办：

1. 给动态版增加低开销诊断，定位全词表 `max + logsumexp` 与小型 GPU 操作的时间占比；
2. 在保持约16%无损 token 压缩的前提下，把200题时间从45秒压回约30秒；
3. 实现论文几何平均版本，并与作者代码版严格区分；
4. 使用独立校准集拟合新动态函数，最后再评测保留测试集；
5. 增加随机种子和规模，不把20题结果写成稳定结论。
