## 实际测评链路

1. 运行 `integration/rebalance_easysteer/scripts/run_rebalance_{static,dynamic}_vllm.sh`；
2. Shell 脚本直接调用 `/root/autodl-tmp/venvs/easysteer-vllm026/bin/python`，不要求手动 `activate`；
3. `integration/rebalance_easysteer/eval/` 中的 Python 脚本读取 GSM8K、本地模型和作者公开向量，并构造 `SteeringSpec`；
4. venv 提供 Python、PyTorch 和预编译 CUDA/C++ 依赖，但运行时 `vllm` 和 `easysteer` 均通过 editable 安装指向仓库的 `sources/EasySteer/`；
5. 同一 vLLM 引擎先用 `steering=None` 跑 baseline，再用同一批题和生成参数跑 ReBalance；
6. 修改后的 vLLM 在 EasySteer 层 18 输出（即作者 block 19 之前）的换段边界加入向量；
7. `math-verify` 判分，并将逐题文本、正确性、token、截断和时间写入 `/root/autodl-tmp/results/easysteer/`。

下载的 vLLM wheel 主要提供预编译二进制部分，不是另外运行的原版 vLLM。已验证的服务器导入路径是 `/root/autodl-tmp/projects/srtp-final/sources/EasySteer/vllm-steer/vllm/__init__.py`。

静态版和动态版配置为使用同一个作者公开向量 `steer_vector_layer19_conf_mixed.pt`。静态版固定使用 `-1`；动态版从 `-1` 开始，随后由逐请求置信度和方差状态更新系数。此外，静态版会命中 `</think>` 后的换段 token，动态版仅在 think 内注入，因此二者并非只差系数。`sources/ReBalance` 在测评时不会被直接 import，它是作者源码快照；已适配的运行逻辑在修改后的 vLLM 中。
