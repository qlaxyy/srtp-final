# S64-mix05：有界概率混合，固定一批验证

**保留一个新候选，准确率损失上限仍为2个百分点。** 运行参数沿用已验证的256并发异步、BF16、1.5B独立raw向量与fit、layer20、seed42、温度0.7、top-p0.95、16000总生成上限；不做速度参数搜索。新增控制仍有成本，不将“沿用配置”说成耗时一定相同。

旧S64强制结束损失准确率；soft2在top-p之后只加倍已有结束权重，128题与R逐token一致，停止该配置。这次仅改变**S64触发后的采样动作**，不调0.8、64或ReBalance参数。令P为原采样器温度/top-p处理后的分布，采用 `P' = 0.95 P + 0.05 delta_end`，不再次做top-p，也不增加一次采样。

这样，原来被过滤的结束token也有5%概率；原有继续token保持相对比例。结束概率由q变为`0.95q+0.05`，而不是置为1。单步总变差不超过0.05（实数公式），**不是整条轨迹或准确率损失的上限**，多次触发会累积，仍可能阻断纠错。5%是事前固定的设计选择，不扫混合权重，不在旧验证题上调节。

实现只需改变结束列：`z_end' = logaddexp(z_end, logsumexp(z)+log(1/19))`。其他列不变，隐式归一化即上述混合。R先缓存原始logits的max概率，S64也从同一份原始logits读熵/rank，再进入温度/过滤/混合/单次Gumbel采样；新混合概率不反馈为R置信度。计数只跟随真正采样的token。关闭思考后不再干预，重用槽位清空混合标志与计数，异步未发布尾token另记。
